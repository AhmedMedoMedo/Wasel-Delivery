# وصل دليفري (Wasel Delivery)

منصة رقمية متكاملة لربط المطاعم بمندوبي التوصيل الفوري، مبنية بتطبيق React تفاعلي فائق السرعة وتصميم متجاوب مخصص لشاشات الهواتف مع دعم كامل للغة العربية (RTL).

## 🚀 المميزات الرئيسية (Core Features)

1. **حسابات وتصنيفات المستخدمين (User Roles)**:
   - **المطاعم (Restaurants)**: نشر طلبات التوصيل، متابعة المتقدمين من المناديب، اعتماد المندوب الأنسب أو رفضه، تعديل تكلفة التوصيل، وتقييم سرعة أداء المندوب بعد إتمام التوصيل.
   - **المناديب (Delivery Drivers)**: استعراض الطلبات المتاحة فوراً حسب نوع المركبة (موتوسيكل أو سيارة)، التقديم على الطلبات، متابعة المشاوير النشطة، وتأكيد تسليم الطلب واستلام المبلغ.
   - **الإدارة (Admin Dashboard)**: لوحة تحكم وإحصائيات مباشرة تتضمن إجمالي الطلبات، عمولات المنصة المستحقة، عدد المطاعم، عدد المناديب، وسجل العمليات اللحظي.

2. **نظام العمولات (Commission System)**:
   - احتساب عمولة المنصة بقيمة 2.5 ج.م على كل طرف (المطعم والمندوب) عند إتمام عملية التوصيل بنجاح، مع عرض الرصيد المستحق في رأس الصفحة.

3. **حفظ ومزامنة البيانات (Persistence)**:
   - حفظ تلقائي للبيانات وحالة المستخدمين والطلبات والعمولات مع حسابات تجريبية مهيأة للاختبار الفوري.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 19 & TypeScript**: بنية برمجية تفاعلية حديثة مع نمط سياق الحالة (Context API).
- **Vite 6**: بيئة تطوير سريعة وتجميع متقدم.
- **Tailwind CSS v4**: تنسيق حديث يطابق الهوية البصرية الأصلية للمنصة (ألوان البرتقالي والأزرق الداكن وخط تجوال).
- **FontAwesome**: أيقونات متطابقة لكل عناصر الواجهة.

## 💻 التشغيل (Development)

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# فحص الأخطاء البرمجية
npm run lint

# البناء النهائي
npm run build
```
